# DriveView

Первый прототип iOS-приложения для просмотра веб-страниц, обнаружения открытых
MP4/HLS-потоков, сохранения видео и воспроизведения через системный плеер с
поддержкой AirPlay.

## Запуск

1. На macOS установите Xcode 15 или новее и XcodeGen.
2. В каталоге проекта выполните `xcodegen generate`.
3. Откройте `CarPlayYT.xcodeproj`, выберите свою Team и запустите приложение на
   iPhone или симуляторе.

Bundle ID `com.example.CarPlayYT` нужно заменить на уникальный идентификатор.

## Что уже входит

- встроенный браузер на `WKWebView`;
- адресная строка, поиск Google, назад/вперёд и обновление;
- несколько вкладок;
- обнаружение обычных `<video>`, MP4 и HLS;
- библиотека ссылок на устройстве;
- `AVPlayerViewController` и системный выбор AirPlay;
- экран настроек с очисткой данных.

CarPlay пока намеренно не включён в конфигурацию приложения. Для запуска на
автомобильном экране потребуется одобренный Apple CarPlay entitlement, доступный
SDK и совместимый автомобиль. Этот модуль добавляется после проверки основного
плеера на реальном iPhone.
